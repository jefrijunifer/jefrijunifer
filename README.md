# Jefri Junifer Pangaribuan — Personal Website

An editorial, interactive personal website for an academic leader and researcher.

## Design direction
- **Modern Academic Editorial**, in ivory, navy, muted steel blue
- **Glass Ecosystem**: interactive 3D representation of Students, Research, Industry and Society
- **Hybrid structure**: editorial homepage with dedicated About, Leadership, Research and Journey pages
- English-language copy, mobile-friendly, accessible motion fallback
- Curated, verifiable research references

## Run locally
```bash
npm install
npm run dev
npm run build
```

## Deploy
Connected to the Vercel project `jefrijunifer` with its GitHub integration. Production builds use the `main` branch.

## Content notes
- Portrait comes from the GitHub account avatar. Replace with an approved, high-resolution professional portrait when available.
- Leadership narratives describe roles and philosophy without inventing impact metrics or completed partnerships.
- Publication information was curated from the author's publicly listed SINTA/academic profiles. Review and update periodically.
- Undergraduate and master's education history is intentionally omitted from the public website.
